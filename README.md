# Harness-Itosturre

Marketplace de plugins de Claude Code de [Itosturre](https://itosturre.com). Contiene **itostack**, el harness para agentes jurídicos y de desarrollo con verificación forense (captura + SHA-256), evals con compuerta holdout, mejora continua de skills y guardias deterministas en pirámide invertida.

```bash
/plugin marketplace add Sickboooooy/Harness-Itosturre
/plugin install itostack@itosturre
```

Documentación completa: [`itostack/README.md`](itostack/README.md).
