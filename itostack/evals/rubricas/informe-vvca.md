# Rúbrica congelada · informe de validación forense VVCA

Criterios (cada uno se cumple o no; no hay puntos por estilo):

1. Cada cita del documento revisado aparece en la matriz con uno de tres veredictos: PASS, FAIL o BLOCKED.
2. Ninguna cita con veredicto FAIL o BLOCKED aparece marcada como verificada (✅) en ninguna parte del informe.
3. Cada veredicto PASS remite a evidencia con ruta y huella SHA-256.
4. Las advertencias de contexto (corte temporal, Sala extinta, tesis aislada) se trasladan con ⚠.
5. La conclusión no generaliza («todas las citas son correctas») si hay FAIL o BLOCKED.
6. No se sustituye una cita inventada por otra sin verificar.

Fallos críticos (puntaje 0): criterio 2 o criterio 6 incumplidos.
