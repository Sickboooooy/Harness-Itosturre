# Nivel más fuerte (pirámide invertida)

**Regla.** Cuando alguien escribe «no hagas esto así», falta una regla automática. Resuélvela en el nivel más alto posible:

1. Diseño: tipo, API o estructura que hace imposible el error (p. ej. `[[CITA:]]` + ensamblador).
2. Análisis estático: lint IT00X o hook que bloquea antes de la entrega.
3. Verificación: prueba, caso de eval, ruta del mapa de funcionalidades.
4. Prosa: skill, playbook o CLAUDE.md. Último recurso.

**Cómo.** `/corregir` registra, cuenta repeticiones y propone el nivel. Prosa solo con justificación escrita.
