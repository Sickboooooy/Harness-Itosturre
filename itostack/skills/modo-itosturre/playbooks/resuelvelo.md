# Playbook · Resuélvelo (tarea no estándar)

1. Definir qué significa «terminado» y cómo se observará.
2. Diseñar el experimento más pequeño que acerque a la meta.
3. Ejecutarlo y capturar evidencia.
4. Iterar; tras dos intentos fallidos con el mismo enfoque, detenerse y reportar BLOCKED con lo aprendido.
5. Si el procedimiento funcionó y es repetible, proponer convertirlo en skill o script (/construir-palanca).
