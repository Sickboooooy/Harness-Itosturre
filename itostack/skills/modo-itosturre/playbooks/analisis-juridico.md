# Playbook · Análisis jurídico (solo lectura)

1. Reformular la pregunta jurídica y la fecha de referencia.
2. Ordenar el marco aplicable por jerarquía normativa (CPEUM → tratados → jurisprudencia obligatoria → leyes → reglamentos).
3. Verificar cada fuente que se vaya a citar (/verificar-cita para tesis; `verificar.py url` para DOF o LeyesBiblio).
4. Distinguir jurisprudencia obligatoria, tesis aislada y criterio orientador; trasladar advertencias ⚠ de corte temporal.
5. Exponer riesgos procesales y alternativas.
6. Responder con fundamento + comentario + recomendación, y la advertencia fija; lo no verificado se marca ⚠ NO VERIFICADO.
